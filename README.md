# PWBril

Baixe o instalador mais recente em **[Releases → Latest](https://github.com/Natchyos/pwbril-atualizacoes/releases/latest)** (arquivo `PWBril-Setup-x.y.z.exe`).

Depois de instalado, o PWBril se atualiza sozinho: ao abrir, ele confere se existe uma versão nova, baixa em segundo plano e instala quando você fechar o programa. Suas contas e configurações continuam no computador.
